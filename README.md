# AI Nutrition Tracker

Личный проект: Telegram-бот и Mini App для учёта питания, созданные с использованием ИИ. Бот принимает описание блюда или фотографию, запрашивает оценку калорий и макронутриентов у Gemini и предлагает подтвердить запись. В приложении можно настроить профиль, просматривать дневной прогресс и добавлять приёмы пищи вручную.

Стек: TypeScript, Next.js, React, PostgreSQL, Prisma, grammY, Google Gemini API.

## Локальный запуск

Нужны Node.js, PostgreSQL, Telegram-бот с настроенным Mini App и ключ Google Gemini API. Для приёма webhook необходим публичный HTTPS-адрес.

1. Скопируйте `.env.example` в `.env` и заполните переменные. Используйте отдельные тестовые учётные данные.
2. Выполните `npm ci`, затем `npx prisma migrate deploy`.
3. Запустите `npm run dev`. Для Telegram установите `NEXT_PUBLIC_APP_URL` на доступный HTTPS-адрес и выполните `node --env-file=.env scripts/set-webhook.mjs`.

Проверки: `npm run build` и `node tests/callback-authorization.cjs`. Для сборки требуется `DATABASE_URL`; подключение к реальной базе на этапе сборки не требуется.

Оценки питания, полученные от ИИ, приблизительные. Проект демонстрационный и не заменяет профессиональную консультацию. Не используйте его для реальных данных без проверки безопасности, инфраструктуры и соответствующих требований.
